## 一、MTProto 内置代理 vs 客户端 SOCKS5 代理怎么选？

很多新手发现没开全局梯子时，点击别人发来的 `t.me/proxy?server=...` 链接就能直接连上 Telegram，这就是 Telegram 原生支持的 **MTProto 代理**。但它与机场客户端提供的 SOCKS5 / 规则分流通道有本质区别：

| 对比维度 | 公共免费 MTProto 代理 | 自建客户端代理（Clash / 小火箭 SOCKS5） |
| :--- | :--- | :--- |
| **连接门槛** | 无需额外软件，点击链接即可在 App 内启用 | 需配合 [Clash Verge Rev](/posts/clash-verge-guide-2026/) 或 [Shadowrocket](/posts/shadowrocket-guide-2026/) |
| **加密与隐私风险** | 代理服务端无法解密聊天内容，但可统计你的登录 IP 与上线频率 | 流量经自有加密节点直达官网，无第三方渠道统计 |
| **广告与频道强推** | **高发**：多数免费节点会强制在对话列表顶部置顶赞助推广频道 | **无任何强制置顶广告** |
| **媒体下载与通话速度** | 极易拥堵、断流，大文件视频下载经常转圈超时 | 可按节点带宽跑满，语音与视频通话低延迟不断线 |
| **外链打开体验** | 仅代理 Telegram 内部流量，点击群内网页链接依然打不开 | 浏览器与外部应用同步走规则分流，顺畅访问关联网页 |

**选型建议**：公共 MTProto 代理只适合作为临时应急备用入口；日常高频使用、传输大文件或关注账号隐私时，强烈建议配合 [Clash Mi 全平台客户端](/posts/clash-mi-guide-2026/) 或本地 SOCKS5 端口（如 `127.0.0.1:7897`）接入。

## 二、为什么刚注册的账号容易“被盗”或“莫名其妙发广告”？

Telegram 账号被盗通常不是因为官方服务器被攻破，而是以下三种常见社会工程学与环境漏洞所致：

### 1. 假冒“Telegram 中文版”木马客户端
国内搜索引擎排名前列的所谓“电报官方中文版下载站”几乎全部是黑产搭建的钓鱼站点。这些假冒安装包在底层植入了 Session 会话窃取模块，一旦你输入验证码登录，攻击者无需密码即可直接接管你的在线会话并悄悄踢出你的设备，甚至篡改群聊里发送的虚拟币收款地址。

### 2. 登录验证码钓鱼机器人（假安全通知）
骗子会伪装成官方安全提醒账号（名字设为 `Telegram Security` 或 `Verification Bot`），私聊发送“账号存在异常将在 24 小时后封禁，请点击链接核验”。只要你在假网页输入手机号和短信验证码，账号控制权瞬间易主。

### 3. 接码平台二次回收号被顶号
使用一次性接码平台或未知二手号注册的账号，若没有及时踢掉旧设备并绑定独立的两步验证密码，原号码被他人重新购买接码后，对方即可直接登录恢复你的账号。

## 三、Telegram 账号安全加固 5 步实操清单

请在首次登录或发现异常后，立即进入 `设置（Settings） -> 隐私与安全（Privacy and Security）` 完成以下五项核心加固：

| 安全设置项 | 正确配置方式 | 核心防护作用 |
| :--- | :--- | :--- |
| **两步验证（2FA）** | 开启并设置高强度独立云密码 + 绑定个人常用安全邮箱 | 即使他人截获短信验证码或通过接码重登，没有 2FA 密码也无法进入账号 |
| **已登录设备清理** | 进入 `Devices`，检查是否有陌生地区/系统会话并一键 Terminate | 立即踢出历史残留会话或被盗取的异常后台设备 |
| **手机号可见性** | `Phone Number` 设为 `Nobody`，`Who can find me` 设为 `My Contacts` | 彻底避免加群后被恶意爬虫采集真实手机号引发骚扰或社工库关联 |
| **邀请入群权限** | `Invites` 设为 `My Contacts` | 防止陌生人每天把你强行拉进海量垃圾盘群或诈骗频道 |
| **通行密钥 / 锁屏密码** | 开启 `Passcode Lock`（桌面端与手机端均设独立本地解锁码） | 防止他人短暂接触你解锁状态的电脑/手机时直接导出对话与会话文件 |

> **资金安全提醒**：由于 Telegram 群聊与私聊中充斥大量冒充客服、虚假代充与恶意假链接，涉及链上转账或交易工具（如了解 [USDT 稳定币安全基础](/posts/what-is-usdt/) 与 [交易平台风控核验](/posts/okx-review/)）时，务必二次多渠道核对，绝不点击陌生机器人发送的快捷授权链接。

## 四、+86 手机号“双向私聊限制”是什么？如何正确解除？

使用中国大陆 `+86` 手机号注册的新账号，在主动给非联系人发送消息时，经常会收到系统提示：`Sorry, you can only send messages to mutual contacts at the moment`。这并非被彻底封号，而是 Telegram 针对特定高发垃圾消息号段的保护性双向限制。

### 正确申诉解除步骤：
1. 在 Telegram 顶部搜索框输入官方机器人准确用户名：`@SpamBot`（认准蓝色官方认证勾，切勿理会私聊冒充的假机器人）。
2. 点击底部 `Start` 按钮，Bot 会反馈你的账号当前是否受限。
3. 依次点击回复中的 `But I can't message non-contacts!` -> `No, I'll never do any of this!` -> 选择 `accident`。
4. 系统通常会在 15 分钟到 24 小时内自动恢复正常私聊权限。申诉期间请保持稳定、干净的代理节点 IP，避免短时间内在十几个不同国家的免费节点间来回跳跃触发二次风控。

## 六、常见问题解答（FAQ）

### 1. 用免费 MTProto 代理连接 Telegram 时，聊天的文字和图片会被代理搭建者看到吗？
不会。Telegram 协议在客户端到官方服务器之间存在独立的 MTProto 外层传输加密与会话密钥校验，第三方代理节点只能看到你的连接来源 IP、上线时间与流量大小，看不到具体聊天文本。但免费节点常会强制置顶垃圾推广频道，日常仍建议优先使用 [Clash Verge Rev 规则分流](/posts/clash-verge-guide-2026/)。

### 2. 开启两步验证（2FA）后不小心忘记密码怎么办？
如果你在开启两步验证时正确绑定并验证了恢复邮箱（Recovery Email），在登录界面点击 `Forgot password` 可通过邮箱验证码重置；若当初跳过了绑定邮箱步骤且彻底遗忘密码，只能等待官方规定的冷却期后执行 `Reset Account`（将清空全部云端历史消息并重新建号）。

### 3. 如何判断自己下载的桌面或手机端是不是假冒“盗号版”？
最简单的方法是只从官网 `telegram.org`、Apple App Store 或 Google Play 商店安装；不要从任何第三方网盘或中文聚合下载站安装声称“自带汉化、免翻墙直连”的未知安装包。完整正版核对方法见 [Telegram 新手入门安装教程](/posts/telegram-guide-2026/)。

### 4. 为什么我的桌面端 Telegram 突然多出一个陌生 IP 的登录设备？
首先排查是否你正在使用的代理客户端开启了全局切换或同时连接了多台设备；如果设备列表里出现你从未用过的操作系统型号（例如你自己用 Windows，列表里却出现未知 Android 或 Linux 会话），极可能会话文件已被窃取，请立即点击 `Terminate Session` 踢出该设备并修改 2FA 密码。

### 5. 开着代理软件能正常看网页，但 Telegram 桌面端一直显示 Connecting... 转圈怎么办？
这是因为 Telegram 桌面端默认不走操作系统 HTTP 系统代理，只支持直接路由接管或手动填入 SOCKS5 本地端口。你可以在电脑客户端开启 **TUN 虚拟网卡模式**，或者在 Telegram 的 `Settings -> Advanced -> Connection type` 中手动添加自定义代理，填入客户端对应的本地 SOCKS5 端口（如 `127.0.0.1` 与 `7897`），配置方法可对照 [Shadowrocket 与通用代理配置指南](/posts/shadowrocket-guide-2026/)。
