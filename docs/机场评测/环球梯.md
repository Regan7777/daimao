## 环球梯客户端下载与使用流程

| 设备 | 官网教程 | 连接步骤 |
|---|---|---|
| Android | 官方客户端，下载区提供双架构版本 | 登录官网注册的账号，点击快速连接，选择节点 |
| Windows | 官方桌面客户端 | 安装并登录账号，开启系统代理，再快速连接 |
| Mac | macOS客户端 | 安装并登录账号，开启系统代理，再快速连接 |
| iPhone / iPad | Nextin，教程要求可用的外区App Store账号 | 填写站点识别码 `HQ66`，登录账号后连接 |

1. 从上方官网入口注册或登录，核对套餐流量、有效期与设备上限。
2. 在仪表盘下载与设备对应的客户端，并阅读帮助中心教程。
3. Android、Windows和Mac按官网账号登录；iOS在Nextin内先填写 `HQ66`。
4. Windows与Mac按教程打开系统代理，手机端按系统提示允许所需的VPN配置。
5. 选择节点，刷新延迟并连接，再验证常用网站和应用。

iOS教程提示外区Apple ID只用于App Store下载，不要将他人账号登录到系统iCloud。环球梯不支持通用订阅，不能通过领取订阅链接导入Clash、FlClash或Shadowrocket，需使用官方客户端或Nextin。需要此功能可比较[Clash机场分类](/rankings/clash/)。

## 环球梯机场常见问题

### 环球梯最低多少钱？

最低可月付套餐为微享15元60GB/月（微享最低套餐不享受折扣，实付15元/月），另有轻享19元110GB/月、畅享29元200GB/月等。学生套餐为96元/年、60GB/月（按年支付，不享受折扣）；一次性按量包最低39元30GB起（另有99元80GB等）。

### 环球梯有不限时套餐吗？

当前两款一次性套餐的详情都注明自购买日起365天有效，所以属于有期限的按量包，不是不限时套餐。

### 支持几台设备？

学生套餐和轻享最多3台，畅游5台，尊享10台；随行按量包5台，灵活按量包8台。不同套餐限制不同。

### 苹果手机怎么使用环球梯？

按官网教程从外区App Store安装Nextin，输入站点识别码 `HQ66`，再用环球梯账号登录和连接。

### HQ66是优惠码还是客户端识别码？

两者都是。订单中的 `HQ66` 用于限量七折活动，Nextin中的 `HQ66` 用于识别环球梯服务，不能把输入识别码理解为订单已获得折扣。
