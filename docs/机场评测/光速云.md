## 线路架构、节点覆盖与并发设备

- 线路架构：全 IPLC / IEPL 物理专线互联，最高单节点峰值达 2.5Gbps。
- 节点倍率与覆盖：全节点均为 1 倍率，晚高峰不降速；覆盖香港×20、台湾×5~10、日本×10、新加坡×10、美国×10、韩国×2、马来西亚×2、英国、法国、德国、土耳其、泰国、巴西、阿根廷、越南、菲律宾、印度等60+节点。
- 并发设备：不限客户端数量，多设备可同时在线。
- 原生IP与解锁支持：支持 Netflix / Disney+ / ChatGPT / TikTok 等主流平台。

## 官方自研客户端与Nextin使用流程

### Windows 官方客户端

1. 从官网下载 Windows 专属安装包（`gsycloud-2.2.3-windows.zip`）。
2. 解压并运行客户端，输入光速云官网注册的账号与密码登录。
3. 客户端自动同步购买的套餐与节点列表，开启系统代理。
4. 点击“快速连接”或在节点列表中选择延迟较低的节点，连接成功后即可使用。

### Android 官方客户端

1. 在官网下载中心获取 Android 安装包（提供 `arm64-v8a` 与 `armeabi-v7a` 双架构 APK）。
2. 安装后打开 App，输入官网账号登录。
3. 点击连接按钮，系统弹出 VPN 连接请求时点击“确定”或“允许”。
4. 支持节点测速与智能路由分流。

### macOS 官方客户端

1. 下载 macOS 专属安装包（`光速云-2.2.3-macos-universal.pkg`），支持 Intel 与 Apple Silicon 双架构。
2. 完成安装后启动 App，输入官网账号登录，允许系统代理配置后即可一键连接。

### iPhone与iPad使用Nextin

1. 准备外区 Apple ID 登录 App Store，搜索并下载 **Nextin**。
2. 打开 Nextin，输入光速云专属站点识别码 **`gsy`**。
3. 输入光速云官网注册的账号与密码登录。
4. 按照 iOS 系统弹窗提示允许添加 VPN 配置，选择节点后连接。

## 严禁私自拉取第三方订阅与风控限制

光速云仪表盘发布重要风险公告：**严禁用户私自拉取订阅链接导入第三方客户端（如 Clash、Shadowrocket 等），系统风控检测到将直接执行封号处理。** 用户应始终使用官方推荐的自研客户端（Windows/Android/Mac）或 iOS Nextin 方案。

此外：
- 不支持免费试用。
- 特殊套餐与一次性包不支持退款与折扣。

## 光速云常见问题

### 光速云最低月付多少钱？

极速A版为25元/月（168GB/月），选择年付为179元/年（折合约14.92元/月）；另有99元/年的轻量B版专属年付包（折合约8.25元/月）。

### 光速云支持 Clash 或小火箭吗？

**不支持。** 官方发布重要公告明确严禁私自拉取订阅链接导入第三方工具，否则会被系统封号。全平台请使用官方自研客户端，iOS 请在 Nextin 输入识别码 `gsy`。

### 光速云有不限时套餐吗？

有。“致敬斯诺克147永久C套餐”售价147元，包含247GB永久不过期流量，不按月重置、随用随停，折合约0.595元/GB。

### iOS客户端识别码是什么？

Nextin识别码为 `gsy`。注册邀请码则是 `9506F5Sq`。

### 支持几台设备同时在线？

所有套餐均不限制并发客户端与设备数量，多台手机、电脑或平板可同时在线使用。

### 支持免费试用和退款吗？

不支持免费试用，全系套餐不支持退款。建议初次尝试先选月付或小额周期。
